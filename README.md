# 小小夢魔：夢境理財所

給小學生的繁體中文生活理財互動網頁，包含兩個夢境關卡、選擇挑戰、關卡得分、夢境鑰匙與旅程進步成果。

## 本機預覽

直接用瀏覽器開啟 `index.html`，或在此資料夾執行：

```sh
python -m http.server 8000
```

然後瀏覽 `http://localhost:8000`。

## 部署

- **GitHub Pages**：將這些檔案推送到 GitHub，於 Repository 的 **Settings → Pages** 選擇部署分支與根目錄。
- **Netlify**：將資料夾拖曳至 Netlify Drop，或連接 GitHub repository；發布目錄使用 `.`，不需要建置命令。

此網站為純 HTML、CSS、JavaScript，無需後端或安裝相依套件。字型使用 Google Fonts，離線時會自動使用系統字型。
